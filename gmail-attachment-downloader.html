📎 Gmail Attachment Downloader

Download attachment Gmail berdasarkan prefix nama file (mis. DAA_T1, PWB_A_T2), berjalan 100% di browser Anda.

1. Konfigurasi OAuth Client ID

Anda perlu membuat OAuth Client ID sendiri di Google Cloud Console (gratis, sekali setup). Klik "Cara Membuat Client ID" di bawah untuk panduan lengkap.
1. Buka console.cloud.google.com → buat project baru (atau pilih yang sudah ada).
2. Buka menu APIs & Services → Library, cari Gmail API, klik Enable.
3. Buka APIs & Services → OAuth consent screen, pilih External, isi nama app & email, simpan. Tambahkan diri Anda sendiri di Test users.
4. Buka APIs & Services → Credentials → Create Credentials → OAuth client ID.
5. Pilih Application type: Web application.
6. Di Authorized JavaScript origins, tambahkan alamat tempat file HTML ini dibuka, misalnya:
  - http://localhost:5500 (jika pakai Live Server), atau
  - alamat domain hosting Anda (harus https, kecuali localhost).
Catatan: membuka file langsung via file:// tidak didukung Google OAuth. Gunakan extension "Live Server" di VS Code, atau jalankan python -m http.server lalu buka http://localhost:8000.
7. Copy Client ID yang dihasilkan, tempel ke kolom di atas.
